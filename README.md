# PA Skills Portable

[![Release](https://github.com/harshalambani/platform-agnostic-skills-portable/actions/workflows/release.yml/badge.svg)](https://github.com/harshalambani/platform-agnostic-skills-portable/actions/workflows/release.yml)

Document-processing skills for bank statements, credit cards, Form 26AS,
broker ledgers, GnuCash books and Indian income-tax workings, packaged as one
portable folder in the
[PortableApps.com Format](https://portableapps.com/development/portableapps_format).
Extract it anywhere and run `PASkillsPortable.exe`; a local Gradio app opens in
its own window (or in your browser if the WebView2 window is not available).

The package bundles Python, the pip dependencies, Tesseract OCR, Poppler and
qpdf. The language model is not bundled. Skills that use one talk to
[Ollama](https://ollama.com) or any OpenAI-compatible endpoint that you run
yourself, so you choose the model and your data stays on your machine.

## Install (end user)

1. Download the latest `PASkillsPortable_<version>.paf.exe` installer or
   `PASkillsPortable_<version>.zip` from
   [Releases](https://github.com/harshalambani/platform-agnostic-skills-portable/releases).
2. Install it, or extract the zip to any folder (a USB drive works).
3. For skills marked "Yes" in the LLM column, start Ollama and pull a chat
   model, or add an OpenAI-compatible endpoint in the Settings tab.
4. Run `PASkillsPortable.exe`.

No Python install is needed.

The build is not code-signed, so Windows may warn the first time. SmartScreen:
choose **More info**, then **Run anyway**. Smart App Control, if it is on,
blocks unsigned apps with no override; use a PC without it. The source and the
build are public in this repository.

## Run from source

```powershell
git clone https://github.com/harshalambani/platform-agnostic-skills-portable.git
cd platform-agnostic-skills-portable
git lfs pull
py -3.13 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m ui.webui
```

Requirements: Python 3.13 or newer, Git LFS (the native binaries under
`vendor/` are LFS files), and an LLM endpoint for the skills that use one.
In source mode Tesseract, Poppler and qpdf must be installed and on PATH for
the skills that need them; each skill's guide lists what it needs.

## Tests

```powershell
cd src
python -m pytest ..\tests\ -q
```

CI runs the same suite from the dependency lock.

## Build

```powershell
python bundling\build.py --version 0.5.0 --skip-pull
```

This produces the frozen app, the PortableApps wrapper, the `.zip` and the
`.paf.exe` installer under `dist/`. See [BUILDING.md](BUILDING.md).

Pushing a `v*` tag runs `.github/workflows/release.yml`, which builds, smoke-tests
the frozen app (start it, expect HTTP 200), and publishes a GitHub Release with
the `.paf.exe` and the `.zip`.

## Layout

```
src/agents/      skills: one skill_*/ folder each (skill.yaml, agent.py, AGENT.md)
                 plus registry.py and base_agent.py
ui/              the Gradio app: webui.py (entry point), tabs/, settings, runner
bundling/        build.py, the PyInstaller spec, templates, launcher and installer tools
vendor/          Tesseract, Poppler and qpdf (LFS)
docs/            generated user guide and developer reference, hand-written guides
tests/           pytest suite
scripts/         gen_docs.py and CI checks
```

Endpoints are kept in `Data/settings/config.yaml` and managed from the Settings
tab; no hand-editing is needed.

## Adding a skill

Create `src/agents/skill_<name>/` with a `skill.yaml` manifest, an `agent.py`
that exports `run()`, and an `AGENT.md` prompt if it uses the LLM. The registry
finds it by its manifest and the UI builds the tab from it. Add a `help:` block
(see [docs/dev/help-block-schema.md](docs/dev/help-block-schema.md)), then run
`python scripts/gen_docs.py`. Details are in
[docs/dev/editing-help.md](docs/dev/editing-help.md); the full inventory is
[docs/dev/skills-reference.md](docs/dev/skills-reference.md).
